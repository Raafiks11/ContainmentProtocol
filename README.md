## 🕹️ How to Play
1. Download the `.zip` file from the [v1.0.0 release](https://github.com/Raafiks11/ContainmentProtocol/releases/tag/v1.0.0).
2. Extract the contents into a folder of your choice.
3. Run `ContainmentProtocol.exe`.

### Controls
* **WASD:** Move
* **Mouse:** Look around
* **Shift:** Sprint
* **E:** Interact
* **Esc:** Pause
